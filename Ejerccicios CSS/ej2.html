Lenguajes de marcas

1. Introducción

CSS son las Hojas de Estilo en Cascada (Cascading Style Sheets). Es un lenguaje estandarizado por el W3C para aplicar formato a documentos web. Permite separar los contenidos de la página y la configuración de su aspecto.

2. Ventajas de separar contenido y presentación

Al utilizar HTML y CSS se separa el contenido del documento del formato de presentación. Esto evita la duplicidad de código y permite aplicar la misma hoja de estilos a distintos documentos HTML.

  • Mejora de la accesibilidad.
  • Mayor flexibilidad en la presentación de la información.
  • Evita la duplicidad de código de presentación.
  • Los resultados de presentación son predecibles.

3. Soporte de los navegadores

La adopción de CSS por parte de los navegadores ha requerido un largo periodo de tiempo. La parte del navegador que interpreta el código HTML y CSS se denomina motor.
